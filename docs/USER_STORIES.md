# VidPress — User Stories

## Upload & Compress
- As a user, I want to upload a video file so that VidPress can compress it for me
- As a user, I want to see the compression progress so I know when it's done
- As a user, I want to download the compressed video so I can use it

## Quality & Size
- As a user, I want the compressed video to look visually identical to the original so I don't lose quality
- As a user, I want to know how much space I saved so I can see the value

## API
- As a developer, I want a REST API so I can integrate compression into my own app
- As a developer, I want to poll a job ID so I can check compression status programmatically
- As a developer, I want a webhook so my app is notified when compression finishes

## Billing
- As a user, I want a free tier so I can try the service before paying
- As a user, I want to pay per GB compressed so I only pay for what I use
